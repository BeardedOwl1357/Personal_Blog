# Demand Side Parameter selection

## Definition / Formula

When we are creating the issue tree using demand-side methodology, we can use some standard parameters

## Explanation

The parameters in question are
- Age
- Income
- Location
- Gender
- Occupation
- Country
- Literacy rate
- Mobile peneteration
- Internet peneteration

These allow us to segment the population correctly
